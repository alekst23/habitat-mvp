Read AGENTS.md and docs/development/ctx-contract.md. Reuse the source issue when
it already describes the request. Create another issue only for distinct work in
scope, after searching existing issues/MRs. Capture expected and observed behavior,
reproduction/evidence, constraints and open questions. Read back uncertain writes.
Use "Publishing GitLab Markdown" in docs/development/ctx-contract.md when saving
the issue body; verify the saved formatting and link targets before handing off.

Link new issues to their source. Filing intake is not completed triage or an
approved implementation plan. Hand off to ctx-issue-triage within planning.
