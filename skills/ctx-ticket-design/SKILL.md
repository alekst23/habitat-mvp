name: ctx-ticket-design
description: Define the smallest solution and required contracts for a scoped implementation ticket.
---

Read the ticket, linked spec and integrated dependencies. Work from the correct
epic base on the ticket branch; preserve unrelated changes. Record the solution
approach, touched boundaries, contracts, failure behavior and AC mapping. Reuse
existing design and abstractions where they fit. Add technical.md only when useful.

No business implementation in this phase. Commit the design and record its SHA in
the operation report before ctx-ticket-tests. Missing product intent returns to
planning; a routine implementation choice does not require another approval.
