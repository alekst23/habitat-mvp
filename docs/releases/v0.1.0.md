# Habitat v0.1.0

This source release captures the local agent workspace and review workflow. It
does not deploy or update the earlier hosted submission at `c0839a4`, and its
validation is separate from historical GitLab pipeline results.

## Included

- **One agent workspace.** The form and collapsible assistant edit the same saved
  draft. Owners review settings, permissions, funding and schedule in one place.
  Durable runs retain progress, owner questions, results and recovery state.
- **Setup accounting.** Assistant costs are attributed to the current workspace
  and included in the agent's available service balance. Activation records the
  charge once; resets and waivers preserve provider usage and unresolved holds.
- **Controlled public research.** Web search through Brave and public page reads
  have independent Off, selected-site, excluded-site and all-public-site levels.
  Owners approve disclosure of the visible goal and site rules. A separate public
  planner chooses queries and pages; private context, files and conversation are
  excluded. AICL checks exact broker requests, current permissions and reserved
  costs. The earlier hosted-search bypass remains disabled.
- **Review inbox.** Search and filter past runs, mark them Seen or Saved, and
  review Markdown reports, sources, activity and costs together. Output versions
  and partial drafts remain accessible.
- **Action inspection.** Workspace logs, inbox activity and full Audit open the
  same request/result inspector with saved inputs, returned data, errors, usage,
  costs and downloadable JSON. New research records include planner inputs and
  results, approved network requests and returned extracted evidence. Inspecting
  saved work does not dispatch model or network work.

## Boundaries

The [AICL ethos](../../AGENTS.md#aicl-ethos) remains the development standard.
This release is not a claim of whole-application compliance or production
readiness. Live research requires operator provider configuration and a verified
local worker image. Gmail and Reddit integrations remain unavailable in the
unified workspace. Encrypted agent-content storage remains planned work, not an
implemented release feature.

Older actions show only retained evidence and label missing fields. Saved model
context and parsed adapter results are not complete provider HTTP transcripts;
credentials, raw response headers and raw page HTML are not newly captured.

## Validation

Local validation for this release snapshot:

- **1,474 backend tests passed**, combining the broad run with targeted reruns.
  Command: `PYTHONPATH=backend:backend/tests:scripts .venv/bin/python -m pytest backend/tests -p ctx_pytest_ac -q`.
  Four stale migration, route and asset fixtures were corrected. Six tests needed
  permission to bind local fixture servers; the fixed-port startup check ran
  while the demo was briefly stopped. The three opt-in Chromium tests and two
  Docker containment tests also passed with their local fixtures enabled. No
  unresolved failures or skips remain in this combined backend evidence.
- **14 JavaScript/browser checks passed** with `node --test tests/*.test.cjs`.
- **270 workflow tests passed** with `.venv/bin/python -m unittest discover -s tests/workflow`.
  Fixture commits used a process-only `commit.gpgsign=false` override to avoid
  inheriting the developer's signing setup; repository signing settings were
  unchanged.
- `scripts/ctx_workflow.py validate` passed. `scripts/ctx_design.py --all`
  confirmed structural validity only; it does not establish new epic acceptance.
- Independent review found no release-blocking issues within its bounded
  security and integration scope. Action inspection was verified in the local
  browser without additional model calls or provider charges.

These are local results. This GitHub repository has no configured Actions
workflows; this release does not claim a new cloud CI run or hosted deployment.
All automated verification used fixtures and existing local browser/container
runtimes, without paid provider calls.
