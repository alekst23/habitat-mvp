## Dependencies
E11-1.

## Design
Owns the canonical creation service and first-party web-app tools (`create_instance`, `InstanceOperations`, tool registry), plus connection and network policy: connections, OAuth, secret store, credential broker, `NetworkPolicy` and SSRF guard, the `WorkAuthorization` dispatch gate, the work executor port with its deterministic fake, and the simulated-work and confirmation routes. Features: aicl-control-plane (F1-S14 to F1-S16) and connection-network-policy (F2-S1 to F2-S11).

## Solution approach
Add `backend/aicl/creation/`, `connections/`, `network/` and `work/`. `create_instance` validates against the one-template catalog and writes the draft instance, grants and audit event in one transaction with `(tenant_id, idempotency_key)` idempotency. `InstanceOperations` implements `set_lifecycle`, `set_capability`, `set_limits`, add and remove network domain, `resolve_gate`, `attach_connection` and `detach_connection` with `expected_version`. The tool registry exposes only `list_templates`, `create_instance` and `read_instance` at `POST /app-tools/{name}`. Implement the OAuth begin and callback with state, PKCE and scope checks against `FakeProviderOAuth`, AES-256-GCM `SecretStore`, `CredentialBroker`, revocation with the provider-failure path and startup sweeper, `authorize_destination` with the SSRF rules, and `authorize_and_dispatch` with the ten fixed checks, `FakeWorkExecutor`, and the reconciler.

## Contracts
Own CreateInstanceRequest, CreateInstanceResult, InstanceOperations and WebAppToolSchemas in `docs/design/aicl-control-plane/technical.md`; own Connection, ConnectionAttachment, NetworkPolicy, CredentialBroker, ProviderOAuthPort, WorkAuthorization and WorkExecutorPort in `docs/design/connection-network-policy/technical.md`. Consume AuthContext, AgentInstance, BudgetPort, PriceTable, AuditEvent and ActionConfirmation from E11-1. Consumers: E11-3, E11-4, E11-5. Configuration rows owned: AICL_PUBLIC_BASE_URL, AICL_SECRET_ENCRYPTION_KEY, AICL_PROVIDER_MODE, AICL_EXECUTOR_MODE, AICL_EXECUTOR_TIMEOUT_SECONDS, AICL_HOLD_STALE_SECONDS.

## Verification
Integration tests through the real service and `/app-tools/*`: creation idempotency, conflict and validation; tool schemas rejecting tenant, owner, credential and confirmation arguments; lifecycle, capability, limit, domain and version-conflict operations; attach rules; OAuth state, PKCE, replay, expiry and scope shortfall; revocation including provider failure and the crash sweeper; gate order and each denial; confirmation single use, expiry and payload mismatch; over-measured and unknown outcomes through the fake executor; no credential in any result, audit event or log; startup rejection of non-fake modes. Unit tests cover host normalization and SSRF address classes. No browser test (UI is E11-3 to E11-5).
